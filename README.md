# Juego Mundial 🏆

![Godot](https://img.shields.io/badge/Godot-4.6-478cbf?logo=godot-engine&logoColor=white)
![GDScript](https://img.shields.io/badge/Lenguaje-GDScript-5b9bd5)
![Proyecto](https://img.shields.io/badge/Tipo-Proyecto%20Escolar-success)

Juego 2D inspirado en Extreme Pamplona, con tematica del Mundial de futbol. ⚽

El objetivo es escapar de un enemigo, superar obstaculos y llegar a la meta final: la Copa del Mundo. 🌍

## Descripcion 🎮

Este proyecto fue desarrollado para la materia Desarrollo de Videojuegos del Instituto Politecnico Modelo (4 C CSTC), dictada por Santiago Beitia.

La aventura recorre distintos paises, donde cada nivel representa el intento de "ganar" el Mundial.


Pierdes si el enemigo te alcanza o si destruye la copa antes de que llegues.

## Controles ⌨️

- Izquierda: A o Flecha Izquierda
- Derecha: D o Flecha Derecha
- Salto: W, Flecha Arriba o Espacio

## Tecnologias 🧰

- Godot 4.6
- GDScript
- Addon de camara Phantom Camera

## Estructura Del Proyecto 📁

- project.godot: configuracion principal
- assets/: imagenes, sprites y recursos visuales
- addons/phantom_camera/: plugin de camara
- src/: escenas y scripts del juego (jugador, enemigo, niveles, UI)
